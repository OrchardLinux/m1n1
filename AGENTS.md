# Agent instructions

This is Orchard's m1n1: Asahi's m1n1 with Hoolock's and Orchard's patches on
top. LLM-assisted work is welcome here, but it stays in Orchard. Never
upstream it: no patches, pull requests, issues or comments to Asahi's or
Hoolock's m1n1. Asahi does not accept LLM-assisted contributions.

Orchard carries its m1n1 changes as patch files in `boot/m1n1/` of the orchard
repository; follow orchard's AGENTS.md for how to change and build them.
